# students/

每位同学在**本目录**下新建自己的文件夹，最终长这样：

```text
students/
└── 20260000001-张三/
    ├── stage1.md
    ├── stage2.md
    └── stage3/
        └── result.txt
```

命名规则：

- 格式是 `学号-姓名`，**学号在前，姓名在后**。
- 中间是一个英文短横线 `-`，不要空格，不要用中文的 `－`。
- 示例：`20260000001-张三`、`20260000002-李四`。

注意事项：

- 只在自己的文件夹里写文件，不要动别人的。
- 文件名必须完全一致：`stage1.md`、`stage2.md`、`stage3/result.txt`。
- `stage3/result.txt` 由根目录的 `task3.py` 自动生成，不要手改。

还没开始？先看根目录的 [README](../README.md)。
